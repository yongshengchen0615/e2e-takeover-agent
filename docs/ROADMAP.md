## 成功標準

1. 人工接管時，AI 不會再對同一頁面發出操作。
2. 完成登入後使用原有的 browser context 繼續，而不是新建工作階段。
3. 不在日誌、截圖或 Git 中保留密碼、OTP、Cookie 或登入工作階段儲存檔。
4. 非本機測試須明確啟用；帶有副作用的操作須先完成安全控管再開放正式環境。
5. 測試結果分開標記「單元測試」、「真瀏覽器整合測試」、「實際專案 E2E」及「平台外掛安裝測試」。
